# 強力右鍵 — 設計

2026-11-15，和 Jeff 討論後定案。

## 要什麼、為什麼

在網頁上看到一段想留下的文字：選起來 → 右鍵 → 「存起來」→ 變成一個檔。沒有下一步，先亂存，
整理是另一個議題。重點是快，以及這個右鍵選單之後能當其他專案的入口（丟圖、截圖再丟…）。

## 目標

- 選取文字後右鍵，出現自己的選單（蓋掉網頁原本的），點一下就存成檔。
- 存下來的檔帶著來源網址與標題。
- 選單內容由收件服務決定：以後加一個動作只改服務，腳本不用動。
- 設定零打字：開一次設定頁、裝腳本，就連上。

## 不做（第一版）

- 圖片、截圖、整頁。
- 轉送到 rawtxt / pokkit / 其他專案。
- 對外開放（手機、別台電腦）。服務只聽 127.0.0.1。
- 管理、搜尋、整理存下來的檔。

## 做了會算失敗的事

- 沒選字的時候也蓋掉右鍵 —— 會干擾正常上網。
- 任何網頁都能偷偷往硬碟寫檔（收件口沒有金鑰，或金鑰被網頁讀走）。
- 金鑰或私人網域進 repo。

## 考慮過的做法

| | 做法 | 取捨 | 結果 |
|---|---|---|---|
| 入口 | 快捷鍵開 nano 貼上存檔 | 有終端機手感，但多一個視窗、多幾個按鍵 | 不選 |
| 入口 | 快捷鍵直接把剪貼簿存成檔 | 最快，但拿不到來源網址 | 不選（之後可以當另一個入口） |
| 入口 | 檔案總管右鍵貼成檔 | 能選位置，但 Win11 右鍵多一層，而且來源在瀏覽器 | 不選 |
| 入口 | 瀏覽器擴充功能 | 原生右鍵選單、每站可用，但要多做一包 | 不選 |
| 入口 | **油猴腳本蓋掉右鍵** | 改起來快、自己的選單不被原生干擾、可愛 | **Jeff 選這個** |
| 收件 | 腳本直接打 rawtxt / pokkit | 少一個服務，但每加目的地都要改腳本、多存金鑰 | 不選 |
| 收件 | **一個小收件服務** | 腳本只認一個地址，動作都加在服務這邊 | **Jeff 選這個** |

## 設計

```
網頁 (油猴腳本)  ──POST /drop──▶  收件服務 (127.0.0.1)  ──▶  資料夾裡的 .md 檔
        ▲                              │
        └────────── GET /menu ─────────┘   選單有哪些項目
```

### 收件服務（Node，零依賴）

- `GET /health` — 活著。
- `GET /menu`（要金鑰）— 選單項目清單 `[{ id, label, accepts }]`。
- `POST /drop`（要金鑰，JSON）— `{ action, kind, text, url, title }` → 執行該動作 → `{ ok, name }`。
- `GET /setup` — 設定頁，只給本機直接開（見下）。
- `GET /power-right-click.user.js` — 腳本本體，不含任何金鑰。

第一版只有一個動作 `save`：寫成 `<時間>_<標題或第一行>.md`，檔頭記來源網址、標題、時間。

設定來自環境變數 / `.env`：`DROP_TOKEN`（沒有就拒絕啟動）、`PORT`（預設 4470）、
`DROP_DIR`（預設 `文件\power-right-click`）。

### 金鑰怎麼到腳本手上

設定頁 `/setup` 的 HTML 裡帶著金鑰；腳本發現自己跑在設定頁上，就把金鑰收起來。使用者不用複製貼上。

設定頁只在下面全部成立時才給：連線來自本機、Host 是 127.0.0.1 / localhost、沒有任何代理或
Cloudflare 加的標頭、瀏覽器標示這是直接開啟（不是別的網站嵌入或載入）。頁面禁止被嵌入、不快取。

### 油猴腳本

- 右鍵時有選取文字 → 擋掉原本選單，在游標旁顯示自己的選單。沒選字 → 完全不動。
- `Shift + 右鍵` 永遠是原本的選單。
- 點項目 → 送出 → 右下角閃一下「已存 <檔名>」或錯誤原因。
- 選單項目用上次從服務拿到的清單（先顯示、背景更新），服務沒開也至少有「存起來」。
- 選單畫在 Shadow DOM 裡，不受網頁樣式影響；網頁內容一律當純文字放。

## 我自己定的（不是 Jeff 說的）

- 存成 `.md`、檔名用時間加標題片段。
- 只在有選字時蓋掉右鍵。
- 第一版只在本機、不掛 CloudPipe：掛上去需要公開 repo 與新網域，而 Jeff 還不確定要不要從別處用。
- 開機自動啟動用啟動資料夾裡的捷徑。
